# Must-cover list for the questionnaire-drafting test (written BEFORE the agent ran)
Trial: NCT05730036 (linvoseltamab vs EPd, RRMM). Site: Levine Cancer Institute, Charlotte NC.
Each item must appear in the agent's pre-fill OR its questionnaire. "R" = needs research beyond the synopsis.

M1  Eligible patient volume (1-4 prior lines incl. lenalidomide + PI; no prior pom/elotuzumab; no prior BCMA immunotherapy)   [Incl 3, Excl 2, Excl 6]
M2  Competing trials for the same patients (pre-fillable from ClinicalTrials.gov)                                              [Excl 6, population]
M3  Inpatient admission capacity for linvoseltamab step-up dosing                                                               [R: drug label/prior studies]
M4  CRS/ICANS management: tocilizumab on hand and/or a written SOP                                                             [R; AESI outcomes]
M5  ICU access                                                                                                                  [R]
M6  Pomalidomide REMS certification for prescribers/pharmacy (EPd comparator arm)                                             [R: comparator arm]
M7  Bone marrow biopsy and MRD sample handling                                                                                  [MRD outcomes]
M8  Imaging for response / extramedullary or CNS disease (CT/MRI/PET)                                                          [Excl 3, IMWG]
M9  Cardiac function testing (echo/MUGA for ejection fraction)                                                                  [Excl 10]
M10 Patient-reported outcomes capability (BPI-SF pain questionnaire / eCOA)                                                    [BPI-SF outcomes]
M11 Startup timelines: IRB (local/central) and contract/budget turnaround
M12 Research staffing: coordinators and investigational pharmacy
M13 Prior bispecific / BCMA trial experience (pre-fillable from ClinicalTrials.gov)
M14 Investigator: likely PI (pre-fillable) and PI interest/commitment (must be asked)

Redundant = a question asking something public (trial counts, bispecific experience, listed PIs, competing trials).
